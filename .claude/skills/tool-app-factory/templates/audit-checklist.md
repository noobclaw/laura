# 审计清单（G5 开发期 / G8a 提审前）

输出格式：每条问题一行「等级 / 问题 / 依据 / 文件:行 / 改法」。等级：**P0** 拒审、崩溃、死路；**P1** 用户可见的错误；**P2** 打磨。P0、P1 清零才过关；修完要复审。

## 1. 购买流
- [ ] 直接购买调用只出现在 Store 层和付费页。
- [ ] 每个锁定入口都打开付费页（逐个列出入口核对）。
- [ ] 价格来自商店，无硬编码；未取到时不显示错误价格。
- [ ] 恢复购买在付费页和设置页都可达，并告诉用户结果。
- [ ] 只认已验证交易，处理退款，交易 finish。
- [ ] 付费页上的每一项都真实存在。
- [ ] 免费额度计数规则与 PLAN.md 一致。

## 2. iOS
- [ ] 每个 `NS*UsageDescription` 存在、写用途、本地化。
- [ ] 代码里引用的系统能力（相册、相机、麦克风、定位）都有对应说明（防 ITMS-90683）。
- [ ] `TARGETED_DEVICE_FAMILY=1`；竖屏锁定；无多余背景模式。
- [ ] 显示名英文；`ITSAppUsesNonExemptEncryption` 已设。
- [ ] 图标 1024 无 alpha；启动屏颜色存在。

## 3. Android（Flutter 路线）
- [ ] 权限声明最小化；前台服务类型；永久拒绝出口；INTERNET 已剥离（除非立项说明）。

## 4. 语言（10 种：en zh-Hant zh-Hans ja ko de fr es pt-BR it）
- [ ] 无硬编码的用户可见字符串；源语言英文。
- [ ] 覆盖率 100%：每个 key × 每种语言都已翻译（App 字符串 + 权限说明 + 显示名）。
- [ ] 占位符与复数正确；德语等长语言无截断（看过截屏）。
- [ ] `store/listing.md` 10 种语言齐全。
- [ ] 中日韩环境下字体回退正常，无方框字。
- [ ] 文案不提别的平台名。

## 5. 错误可见
- [ ] 导入、存盘、权限、购买失败都有具体原因 + 出路。
- [ ] grep 空 catch / `try?` 吞掉的关键路径。

## 6. 数据安全
- [ ] 零联网（或已立项说明）。
- [ ] 写文件原子化；升级后旧数据能读（JSON 带版本号）。
- [ ] 临时文件清理。

## 7. 崩溃与生命周期
- [ ] 空列表、单元素、超长文本、超长音频、极短输入。
- [ ] 双击/连点、快速进出页面。
- [ ] 后台 ↔ 前台、来电打断、拔耳机、锁屏。
- [ ] 长任务：中途删除对象、取消、后台时间用完。
- [ ] 音频/渲染线程不读主线程可变状态。
- [ ] 强制解包、越界下标、除以零。

## 8. 商店文案 vs 实现
- [ ] `store/listing.md`、`store/aso.md`、ASC 内购描述里的每条卖点都真实存在且可达。
- [ ] 截图里的界面都是真实界面。

## 9. 规矩合规（本 skill）
- [ ] 十条铁律逐条过一遍。
- [ ] UIUX 否决项 V1–V9 逐条过一遍（用户拍板偏离的条款注明）。
- [ ] PLAN.md 齐全：楔子、架构、权限、定价、设计简报、里程碑、真机验收清单、立项评分。
- [ ] `store/` 有英文 listing 与 aso.md。
