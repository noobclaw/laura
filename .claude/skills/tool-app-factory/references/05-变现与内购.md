# 05 变现与内购

原文：`PIPELINE.md`「变现与定价标准」。

## 模式
- 默认：**免费 + Pro 一次性买断**（非消耗型）。
- B 端搜索转化型可纯付费下载。
- 走服务端的（2026-09-13 解禁）可以订阅，但 PLAN.md 要写清服务端做什么、月成本多少、挂了能否离线降级，并填数据收集声明。
- **禁广告 SDK**。免费层必须真能用（核心功能 + 数量上限），Pro 解锁「无限 + 进阶」。

## 定价
- 阶梯：练手/填充 $0.99–1.99；标准工具 $2.99–4.99；专业/垂直刚需 $5.99–14.99。
- 锚定：对标头部竞品价的 1/3–1/2。中区用整数 ¥6/12/18/28/38/68/98。
- 上架 3 个月后按转化复盘调价。

## 商品 ID
`<bundleId>.pro_unlock`（App Store 的商品 ID 全账号唯一，不能都叫 `pro_unlock`）。历史例外：remcard。

## 付费页（每个付费门都先打开它）
- 标题跟着触发原因变（「免费额度用完了」「解锁真鼓模式」……）。
- 列出 Pro 的每一项（只写真实存在的功能——G8a 第 8 面会逐条核对）。
- 一个解锁按钮，**价格取商店下发的本地化价**（StoreKit `displayPrice` / Flutter `ProPriceText`），没取到就不显示价格，绝不写死。
- 「恢复购买」入口：付费页和设置页各一个。
- 一句「一次付款，永久拥有，不是订阅」+「支持家人共享」（如果开了）。
- 购买成功：触感 + 动画 + 自动关闭；pending 状态要提示「等待批准」。
- **禁止**任何入口直接拉起付款；禁止用提示条打发用户「去设置里解锁」。

## StoreKit 2 实现要点（原生路线）
- 启动时：`Task { for await r in Transaction.updates { … } }` 常驻；然后 `Product.products(for:)` + 遍历 `Transaction.currentEntitlements`。
- 只认 `.verified` 交易；`revocationDate != nil` 视为退款，撤销 Pro。
- 处理完交易必须 `await transaction.finish()`。
- Pro 状态缓存到 UserDefaults，离线启动也能用（`currentEntitlements` 本身也走本地缓存）。
- 恢复：`AppStore.sync()` 后重刷 entitlements，并告诉用户结果（找到/没找到）。
- 本地测试：`.storekit` 配置文件挂在 scheme 的 Run 上；`project.yml` 里把 `*.storekit` 从 sources 排除。

## 免费额度的计数规则（要在 PLAN.md 写明）
- 按什么计（开始分析的次数 / 成功的条目数）。
- 失败的算不算、删除后退不退——这是用户能感知到的规则，**默认对用户友好：失败不计**，除非用户拍板另定。
