# 08 多语言（硬性要求，2026-11-25 用户拍板）

**每个 App 都必须完整支持 10 种语言，翻译没做完不准出包（包括 TestFlight）。**
用户原话：「app 的 skill 必须要支持多语言」。

## 语言清单（固定）

| 代码 | 语言 | 备注 |
|---|---|---|
| `en` | English | 源语言；ASC 主语言 English (U.S.) |
| `zh-Hant` | 繁體中文 | 台湾/香港用语，不是简体转码 |
| `zh-Hans` | 简体中文 | |
| `ja` | 日本語 | |
| `ko` | 한국어 | |
| `de` | Deutsch | 最长，按英文 1.4 倍预留宽度 |
| `fr` | Français | 冒号、问号前加空格 |
| `es` | Español | |
| `pt-BR` | Português (Brasil) | |
| `it` | Italiano | |

## 覆盖范围（四样都要翻）

1. **App 内全部用户可见文字**：按钮、标签、提示、错误、空状态、付费页、成就/任务名、导出文件里的文字。
2. **系统权限说明**：`NS*UsageDescription`（iOS 用 `InfoPlist.xcstrings`；Flutter 用各 `.lproj/InfoPlist.strings`）。
3. **显示名**：`CFBundleDisplayName` 每种语言都写（品牌名保持英文，可加本地化副名，如「Groovelens 鼓譜」只在中日韩用）。
4. **商店文案**：`store/listing.md` 10 种语言的名称/副标题/关键词/描述/What's New；ASC 每个本地化都要填。

## 规则

- **App 名、产品名、商品名不翻译**（Groovelens、Pro）。
- 保留所有格式占位符原样：`%@`、`%lld`、`%1$@`、`\(…)`，顺序需要调换时用位置参数。
- 复数用 String Catalog 的 plural 变体（en/de/fr/es/pt/it 需要 one/other；中日韩只要 other）。
- 术语表先定再翻：每个 App 在 `PLAN.md` 写一张术语表（例：鼓 = kick/snare/hi-hat 在各语言的标准叫法），全 App 一致。
- 语气：简短、动词开头、不用感叹号堆砌；按钮 ≤2 个词（德语可 3 个）。
- 不能机械直译的（双关、口号）按意思重写。
- 繁中用台湾习惯词（影片、資料、設定、匯出），不要用「视频」转繁体的「視頻」。

## 流程

### 原生 SwiftUI
1. 代码里只用 `String(localized:)` / `Text("字面量")` / `LocalizedStringKey`，不拼接句子。
2. **让工具导出 key，不手猜**：CI 构建 job 里跑
   `xcodebuild -exportLocalizations -project <App>.xcodeproj -localizationPath ci-out/loc -exportLanguage en`，
   把 `en.xcloc/Localized Contents/en.xliff` 推到结果分支读回。插值参数的格式符（`%lld`/`%@`/`%lf`）以导出结果为准。
3. 用脚本把翻译写进 `Localizable.xcstrings`（JSON：`strings.<key>.localizations.<lang>.stringUnit {state: translated, value}`）和 `InfoPlist.xcstrings`。
4. `project.yml` 里声明 `options.developmentLanguage: en`，并在 `knownRegions` 列出全部 10 种。
5. CI 加**覆盖率闸门**：每个 key × 每种语言都有 `translated` 状态，否则构建失败。
6. CI 冒烟：用 `-AppleLanguages "(zh-Hant)"` 等参数启动截屏，至少看 en / zh-Hant / ja / de 四张，检查截断、溢出、方框字。

### Flutter 壳
1. 文字走 `tr(zh:, en:)` → 扩成 10 语言的 ARB（`lib/l10n/app_<lang>.arb`），`flutter gen-l10n`。
2. `flutter test` 加一个测试：所有 ARB 的 key 集合与英文一致、没有空值。
3. iOS 权限说明放 `ios/Runner/<lang>.lproj/InfoPlist.strings`。

## 关卡位置

- **G2**：PLAN.md 写术语表。
- **G3**：写代码时就用可本地化 API；源语言英文。
- **G4**：覆盖率闸门通过（10 × 全部 key）。
- **G6**：四种语言截屏看过。
- **G8a 第 4 面**：逐语言抽查付费页、错误提示、权限说明；商店文案 10 种都在。

**没做完翻译 = 不出包**。用户要求先给英文测试包时，必须明说「这是只有英文的内测包，正式包前补齐」，并在 BACKLOG 标注。
