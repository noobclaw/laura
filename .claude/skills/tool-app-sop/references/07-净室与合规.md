# 07 净室与合规

## 1. 反编译与竞品源码的使用边界

| 可以 | 不可以 |
|---|---|
| 盘点功能、页面、设置项、付费点、弹窗时机、权限、服务 | 复制任何一行代码（包括「改个变量名」） |
| 记录行为参数（默认并发、重试次数、间隔天数）作为对照 | 复制资源：图标、图片、音效、字体、动画、布局文件 |
| 用自己的话描述算法思路，再按规格从零实现 | 复制文案原句（strings.xml 只用来盘点功能，我们的文案自己写，10 语言） |
| 引用公开商店页的价格、评分、评论数 | 使用包里的任何密钥：OAuth 客户端 ID/密钥、API key、广告 ID、签名证书 |
| — | 用竞品的服务器、回调地址、远程配置 |

开源竞品按 CLAUDE.md「来自 GitHub 的选题」两条：permissive 可依赖 + 署名；GPL/AGPL/无许可证只按自写规格重写，PLAN 写明「参考 owner/repo，未复制代码与资源」。

TEARDOWN 开头必须写一行净室声明（范例见 `apps/haul/TEARDOWN-total.md`）。

| 竞品功能 | 条款 | 我们 |
|---|---|---|
| 视频嗅探、下载第三方网站流媒体（含 HLS/m3u8）、YouTube 下载 | 5.2.3 | ✕；只下载用户点击的普通文件链接 |
| 奖励换评分/评论、评分才解锁 | 3.2.2(x)、5.6.1 | ✕ |
| 自绘星星评分窗 | 5.6.1 | ✕；用系统 `requestReview` |
| 邀请换权益（奖励安装） | 3.2.2 | ✕ |
| 远程下发可执行脚本改变 App 行为 | 2.5.2 | ✕ |
| 冒充系统清理/加速、虚假警告 | 2.3.1 | ✕ |
| 未声明的数据收集 / 跟踪 | 5.1.1、5.1.2 | 不收集；声明与抓包一致 |
| VPN、代理 | 5.4 | 不做（个人开发者账号不允许） |

## 3. 许可证

PLAN 第 12 节每个库写许可证。MIT/Apache/BSD/MPL 可用并在「关于 → 开源许可」署名；LGPL 只能动态链接或换库；GPL/AGPL 不进 App 包。
