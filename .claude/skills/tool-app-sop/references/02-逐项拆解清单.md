# 02 逐项拆解（TEARDOWN 模板 + 不漏项清单）

范例：`apps/haul/TEARDOWN-total.md`。

## 1. 模板章节

```
# 竞品拆解：<竞品>（<公司>）
> 拆解日期、材料清点、用途边界（净室声明）
## 0. 一句话结论（它卖的是什么、护城河、最大弱点）
## 1. 市场数据（各平台价格、评分、评论数、榜单、上架年份、最近更新、语言数）
## 2. 信息架构（区块 → 子页面表）
## 3. 功能逐项清单（每区块一张表：编号 T-区块-序号 · 功能 · 细节 · 证据 S/R/C/iOS）
## 4. 设置全集、付费与增长机制、权限、第三方服务、远程配置
## 5. 弱点 W1…（每条：现象 · 证据（评论原话摘要/代码位置）· 影响多少人）
## 6. 不照抄清单（违规、扰民、需服务端、我们不需要的）
```

## 2. 不漏项检查清单（逐项打勾，缺一项回去补）

**页面与功能**
- [ ] 每个导航区块、每个子页面、每个空状态
- [ ] 每个长按菜单、每个滑动操作、每个批量操作
- [ ] 每种支持的文件/数据格式（读、写、只读）
- [ ] 引导页（几页、每页卖点）
- [ ] 搜索（范围、过滤器）

**设置**
- [ ] 设置 xml / 设置页的每一行（默认值、可选值）
- [ ] 隐藏/调试开关、重置项

**变现**
- [ ] 每个付费点（商品 ID、价格、买断/订阅、家人共享）
- [ ] 免费版限制（数量、次数、功能）
- [ ] 广告：类型（横幅/插屏/激励）、位置、频率（如插屏间隔）
- [ ] 去广告的所有途径（买、看广告、问卷、邀请）

**增长与留存**
- [ ] 好评弹窗：触发条件（启动次数、天数）、重复间隔、分流逻辑
- [ ] 分享入口与分享内容
- [ ] 邀请/返利机制
- [ ] 推送、通知种类
- [ ] 强制更新（minVersion）

**系统与服务**
- [ ] Manifest 权限逐条，对应哪个功能
- [ ] 后台服务、前台通知、Widget、深链、分享接收（intent-filter）
- [ ] 第三方 SDK 与服务（云 API、广告、分析、崩溃）
- [ ] 远程配置的每个字段（拉黑站点、注入脚本、UA、开关）
- [ ] 本地数据：数据库表、迁移逻辑（是否会丢数据）
- [ ] 网络行为：并发、重试、断点续传、移动网络限制

**口碑**
- [ ] 最近 1 年差评 ≥20 条读过，归类成 W 条
- [ ] 好评里反复夸的点（这是必须对齐的）
- [ ] 各语言版本是否齐（语言数是常见弱点）

## 3. 证据纪律
- 每行功能至少一个证据字母；只有报告说、没找到证据的写「未证实」。
- 评论只写摘要，不贴长原文；一个来源最多引一句 15 字以内原话。
