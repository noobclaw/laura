# 做 app 总规矩（一页速查）

> 2026-09-25 整理。这一页是把散落在各处的规矩汇总起来的**索引加摘要**。原文以这几份为准：`D:\toolapp\CLAUDE.md`（选题标准）、`D:\toolapp\PIPELINE.md`（工厂 SOP G0–G8）、[[立项前挑刺关]]（09-25 新规）。本页和原文冲突时，以原文为准，并回来修正本页。

全流程：**选题 → 立项前挑刺关 → 工厂 G0–G8 → 截图/ASO → 提审/上架 → 真机验收与复盘**。

## 一、选题（进不进 BACKLOG）

**一票否决（直接排除，不打分）**
- 与巨头竞争：主词头部是 Apple/Google/微软/Adobe/字节/腾讯/阿里，或有评价 ≥10 万的免费 app。
- 系统自带就能替代：闹钟、计时器、手电筒、计算器这类，除非付费榜上有实证的差异化。
- 能力天花板：需要出厂标定（dB 声压、血氧）、内容授权（图鉴、法规数据库）、行业资质（医疗判读）。
- 垃圾赛道：清理加速、壁纸、山寨 VPN。

**主选题源**：垂直细分 + 巨头注意不到 + 抱怨最多 + 还没人做或做得不好，四条缺一不可。
- 发现渠道以 Reddit 的职业/爱好圈子为主（养蜂、木工、电工、潜水……），不用泛开发者社区。
- 至少 3 条不同作者的抱怨原话。
- 「圈里还在用 Excel 或纸笔」是最强的信号。
- GitHub 优秀开源项目也可以做选题：permissive 许可证可以移植并署名；copyleft 只读代码、写成规格后自己重写，一行不抄。

**双硬门**：缺口 ≥5/15 **且** 付费验证 ≥15/25。低于线的只进观察池。

**服务端**：09-13 起已放开（256btc.com），但 PLAN 必须写清三件事：服务端做什么、每月花多少钱、服务挂了之后 app 还能不能用。纯本地仍然是加分项。

## 二、立项前挑刺关（09-25 新增，详见 [[立项前挑刺关]]）
1. **先打分，过了硬门才准开工**，工厂取题时再核一遍（TuneBench 是先做后评的反例）。
2. 写出「最危险假设」，并做花钱少的小实验去验证。
3. 加一项「分发」评分（用户怎么搜到你），并做定价核算。
4. Reddit 采集器换上抱怨关键词表，抓附和人数、付费意愿、已经失败过的方案。
5. 查 Google Trends 热度和搜索联想，**热度必须除以竞争来看**。

## 三、工厂 SOP（PIPELINE.md，按顺序，前一关不过不进下一关）
| 关 | 要点 |
|---|---|
| G0 防撞车 | 近 2.5 天 `apps/` 有新提交就跳过本轮；大项目按里程碑算 |
| G1 取题 | 取 BACKLOG 排队中指数最高的一项，再执行一遍否决规则 |

| G2 立项评审 | 写进 PLAN.md：**差异化楔子一句话**（写不出来就换题）、招牌功能架构选型、权限流程（拒绝要有提示、永久拒绝要能跳设置）、定价 |
| G3 开发 | 见下面第四节的铁律 |
| G4 本地验收 | `flutter analyze` 零问题 + `flutter test` 全过。**严禁在本机 flutter build**（8GB 内存） |

| G6 出包冒烟 | CI `build-app.yml` 的冒烟测试必须绿，**亲眼看截屏** |

| G8 上架 | 每周 1–2 个；真机验收过 + 真内购 + release 签名 |

## 四、开发铁律（G3）
- **不许长得一样（防 Apple 4.3(a)）**：TuneBench 09-25 因此被拒。每个 app 都要有：自己的色相（查色相表，和已有的不能在 ±20° 以内）、自己的 hero 形态、至少一处自绘图形、专属图标和启动屏。复制壳之后改名核心层，提审包用混淆（`.ci-obfuscate`）。
- **视觉**：rubric 共 13 条。必须有一个 **signature 炫技动效场景**，logo 缩到 60px 还能认出来，深色和浅色主题都要好看。
- **多语言**：所有用户能看到的字符串都用 `tr(zh:, en:)`，**必须有完整英文区内容**，英文显示名在美区不能和别人逐字同名。
- **iOS 平行检查**：`NS*UsageDescription` 说清用途；只做 iPhone（`TARGETED_DEVICE_FAMILY=1`）；用 SPM，不提交 Podfile；plist 里的中文不许用 Windows 工具直接写进去；小心 ITMS-90683。
- **付费**：免费层要真能用，Pro 一次性买断；**每个付费门都先弹 `showProSheet`**，禁止直接调 `buyPro()`；价格从商店取，不写死；必须有「恢复购买」入口；禁止接广告 SDK。
- **零联网默认**：去掉 INTERNET 权限；需要联网的要单独说明理由。
- **定价**：对标头部竞品价格的 1/3 到 1/2；中区用整数价（¥6/12/18/28）；上架 3 个月后复盘。

## 五、ASO 与商店素材（G8b）
- iTunes API 实打美区 10–15 个主词，写进 `store/aso.md`。**头部评价 <5,000 条的词主攻，10 万条以上的放弃。**
- 标题 = 主词在前 + 品牌名（只要不和别人逐字相同就行）；副标题 = 第二主词 + 楔子；关键词不重复标题里已有的词。**关键词里不放竞品商标**（OhmBench 要删掉 icircuit）。
- **截图自己出**：用 flutter test 渲染真实界面并套上带标题的外框。App Store 1284×2778、Play 1389×2778，中英各一套。第 1 张就是广告位，不许 P 出 app 里没有的功能。
- 评价：第 3 次成功完成核心操作时弹评价请求（90 天冷却）；首周需要 ≥5 条真实评价，这件事要用户去找人。
- 每周复测 4 个主词的排名。

## 六、提审/上架
- **ASC**：主语言设为 English (U.S.)，en-US 本地化要填全；已上架 app 出更新时，每个本地化都要填 What's New。支持网址用 256btc.com/support/。
  - 提交顺序：App 信息 → 年龄分级 → 隐私 → 定价与地区 → 版本页（取消勾选「Sign-in required」）→ 内购 → 提交审核。
  - 操作 ASC 时 Chrome 窗口不能最小化，单选框和复选框用 find+ref 点。
- **中国区**：需要 APP 备案号（蜀ICP备2026049213号 系列）。TuneBench 的名额转给电路台。
- **Play**：封闭测试要 **12 名测试员连续 14 天**，人数以 app 仪表盘上的「目前已有 N 名测试人员选择参与」为准。名单在 `D:\noob\app\Play测试邀请.md`。
- **自身状态必须实查**：上没上架以 iTunes lookup 为准，不看本地记录。
- **CI 绿不等于 TestFlight 里有包**：要去 ASC 的 Build Uploads 看是不是 Failed。

## 七、复盘出来的教训
| 事件 | 教训 |
|---|---|
| 干净闹钟真机不响 | analyze 和 test 都过 ≠ 能用 → 有了 G5/G6 和真机验收 |
| 7 个 app 图标 md5 完全相同 | 图标必须专属 |
| Orbit 上架 6 天 0 评价 | 美区挂了中文名、没有 en-US 本地化 → 英文区内容成了铁律 |
| 09-12 先出包后审计 | 批量改动在出包前必须过 G8a |
| TuneBench 被 4.3(a) 拒 + 品类太挤 | 先打分再开工、不许长得一样、热度要和竞争一起看 |
| 连续 9 天 0 候选 | 「零门槛」的东西一定会被做成免费 → 转向垂直圈子和有门槛的方向 |
