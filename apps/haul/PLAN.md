## 1. 一句话定位

**Haul：把所有云盘、NAS 和手机里的文件放进同一个漂亮、无广告、带锁的地方，还能一键传回电脑、混合播放。**

英文副标题（ASO 草案）：*Files, Clouds & Media Player*。

## 2. 差异化楔子（用户为什么选我而不是 Total）

> Total 有的我们都有；**它没有的**：Face ID 锁整个 App、Wi-Fi 一键传回电脑、云到云直传、无广告、10 种语言、现代设计。**它做砸的**：升级丢数据、播放器没封面、只能同时传 1 个。

## 3. 目标用户

| 人群 | 场景 | 来自竞品的证据 |
|---|---|---|
| 多云盘用户（个人 + 工作账号） | 在 Google Drive、OneDrive、Dropbox 之间找文件、搬文件 | T-C02「无限云账号」是引导页卖点 |
| 有 NAS / 家用服务器的进阶用户 | 用手机浏览 NAS、播影片 | 工具付费榜 FE File Explorer 9 区上榜 |
| 本地音乐/影片收藏者 | 把下载的音乐、课程影片做成播放清单，后台播放 | Total 评论大量提到「用来听音乐」 |
| 注重隐私的用户 | 不想让别人看到某些文件 | W2：评论抱怨没有 App 锁 |

## 6. 信息架构与页面

底部 4 个标签 + 右上齿轮（设置），首屏 = 「文件」。

| 标签 | 首屏内容 | 关键页面 |
|---|---|---|
| **文件**（首屏） | 顶部：全局搜索框 + 分享按钮（分享存储总览卡）+ 齿轮。主体：存储总览环形图 → 位置列表（本机、iCloud、各云账号、NAS）→ 最近文件 → 收藏/合集 | 目录页、文件详情、画廊、PDF、目标选择器、添加位置 |
| **浏览器** | 常用站点格 + 地址栏（底部） | 标签网格、书签、历史 |
| **传输** | 进行中 / 已完成 分段；全部暂停/继续 | 任务详情、Wi-Fi 传输页 |
| **播放** | 播放列表格 + 底部迷你播放器 | 列表详情、全屏播放器 |

### 6.1 设计简报（G2，按 tool-app-factory `references/03-UIUX.md`）

- 原型：**粗野工具 Utility Brutal**（批处理/转换，色相表空位）。
- 色相：信号橙（约 24°，开工前查色相表 ±20° 不撞）；中性底 + 等宽数字。
- 字体：标题 Space Grotesk（OFL）、数字 SF Mono。
- Hero / 自绘图形：首屏「存储总览」环——每个位置一段弧，弧长 = 真实已用空间（V9 承载真实数据）。
- Signature 场景：传输时文件块沿轨道从来源滑向目标（云→云时两端都是云图标），速度越快动画越快。
- 首屏 ≠「标题 + 齿轮 + 卡片列表」（V1）：环 + 搜索框 + 位置条是工具本身；冷启动 0 次点击就看到本机空间（V6）。

## 7. 关键流程

1. **首次启动**：3 页引导 → 「添加第一个位置」（可跳过）→ 文件首屏。
2. **加云账号**：文件首屏「＋」→ 选服务 → 系统登录页（PKCE）→ 回到 App，账号出现在位置列表，并显示空间。
3. **网页下载**：浏览器打开页面 → 点文件链接 → 底部弹出「下载到…」（本机/某云）→ 传输页出现任务 → 完成后通知 + Live Activity 结束。
4. **跨云搬文件**：多选 → 移动 → 目标选择器选另一个云的目录 → 传输页显示「云→云」任务。
5. **Wi-Fi 传回电脑**：传输页「Wi-Fi 传输」→ 显示网址和 QR 码 → 电脑浏览器打开 → 拖拽上传/点击下载。
6. **混合播放**：播放 →「新播放列表」→ 从本机/云选音视频 → 播放，锁屏可控。
7. **上锁**：设置 → App 锁开启 → 下次进入需 Face ID；保险箱里的文件不出现在搜索和最近文件里。

## 8. 变现（必须有内购）

- 免费下载，无广告。
- **Haul Pro 一次性买断 $7.99**（`com.noobclaw.haul.pro`，非消耗型，可家人共享）。
  - 定价依据：Total files pro €5.99 / £4.99 / HK$38 买断，免费版带广告；我们功能更多、无广告，取 $7.99。FE File Explorer Pro 的同类买断价位也在 $5.99–$9.99。
- 免费 vs Pro：

| 能力 | 免费 | Pro |

| 本机、iCloud、Files 位置 | ✅ | ✅ |
| 云账号 / NAS | 合计 2 个 | 无限 |
| 同时传输 | 2 | 1–5 可设 |
| 云到云直传、Wi-Fi 传输 | 每天 3 次 | 无限 |
| 播放列表 | 3 个 | 无限 |
| 视频转音频、批量重命名、保险箱 | — | ✅ |

## 9. 好评引导（铁律 13）

- 时机（任一满足、且距上次 ≥30 天、且安装 ≥3 天）：第 3 次传输成功完成；第一次 Wi-Fi 传输成功；加入第 2 个云账号后浏览成功。
- 两步：自家卡片「喜欢 Haul 吗？」→「喜欢」调系统 `requestReview`；「还不够好」→ 意见反馈（mailto，自动附 App 版本与 iOS 版本，不附任何文件信息）。
- 设置常驻「给我们评分」。
- 禁止：传输出错、付费墙、首次启动 5 分钟内弹窗；不画星星；不以奖励换评分。
- 对比 Total：它在打开 6 次 + 3 天后、每 7 天重复弹，太打扰；我们按成就时刻、30 天间隔。

## 10. 分享（铁律 10）

- 首屏右上分享按钮 → **存储总览卡**（1080×1350）：所有位置的环形图、总文件数、Haul 名称与图标。账号邮箱、文件名默认隐藏，可开关。
- 文件/文件夹分享：系统分享面板；文件夹自动压缩成 zip。
- 播放列表分享：生成列表卡（名称 + 曲目数 + 总时长），不含文件本身。
- 分享卡免费，也是拉新渠道。

## 12. 技术方案（原生 SwiftUI 路线，iOS 17+，只 iPhone 竖屏）

| 模块 | 技术 | 许可 |

| 云 | 直接调 REST：Google Drive v3、Microsoft Graph、Dropbox v2；`ASWebAuthenticationSession` + PKCE；令牌存 Keychain | 自写 |

| Wi-Fi 传输 | Network.framework `NWListener` 自写极简 HTTP + 网页 | 自写 |
| 浏览器 | WKWebView；`WKDownload` 处理下载 | Apple |
| 媒体 | AVPlayer、AVAudioSession、MPNowPlayingInfoCenter、PiP、AirPlay；转音频 AVAssetExportSession | Apple |
| PDF / 预览 | PDFKit、QuickLook | Apple |
| 压缩 | ZIPFoundation（zip）；rar/7z 只读另选库，立项时核许可 | MIT |
| 锁 | LocalAuthentication | Apple |
| 搜索 | CoreSpotlight + 各云搜索 API 并发 | Apple |
| 内购 | StoreKit 2 | Apple |

## 14. 隐私与审核

- 不收集任何数据；App Privacy 填「不收集」。云令牌只在设备 Keychain。
- 审核附件：CI 录屏（铁律 12）；审核说明写明：不提供第三方流媒体下载、浏览器只下载用户点击的文件链接；提供测试用云账号（Google 测试号）。
- 年龄分级：含「不受限网页访问」→ 17+（与 Total 一致）。
