## 3. 缺陷分级

| 级 | 定义 | 处理 |
|---|---|---|
| P0 | 崩溃、丢数据、付费不生效、令牌泄露、违反审核红线 | 阻断，修完重跑全部相关用例 |
| P1 | 核心流程走不通或结果错误、某语言明显错、UX 否决项 | 阻断该里程碑 |
| P2 | 边角、文案、轻微视觉 | 可带进下一里程碑，写进本节 |

## 4. 外部依赖（需要用户做的事，开工前问）

1. Google Cloud / Microsoft Entra / Dropbox 三家开发者后台建 OAuth 应用（iOS 类型、我们的 bundle id 与 URL scheme），把 client id 给我们（不需要密钥）。
2. ASC 建 App 记录（bundle `com.noobclaw.haul`）与 Pro 非消耗型内购。
3. 审核用 Google 测试账号（放 ASC 审核信息，用户自己填密码）。
