# Haul — 测试用例（由 PLAN.md 逐条推导）

> 规则（tool-app-sop 第 5 步）：PLAN.md 里**每一条需求**（第 4 节对照表每行 ↑/＝、第 5 节每个创新、第 7–10 节每个流程与规则）至少 1 条用例；用例 ID 里写来源需求号，便于反查覆盖。
> 字段：ID · 来源 · 前置 · 步骤 · 预期 · 优先级（P0 阻断上架 / P1 核心体验 / P2 边角）· 里程碑 · 方式（A=XCUITest 自动 / U=单元测试 / M=人工模拟器 / D=真机）。
> 「预期」必须可判定（看得见的文字、数字、状态），不写「正常」「流畅」。
