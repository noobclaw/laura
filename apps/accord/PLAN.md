# Accord — PLAN

> 状态：🟢在做（设计稿阶段）　　路线：原生 SwiftUI（iOS 17，iPhone 竖屏）　　Bundle：`com.noobclaw.accord`
> 商店名（暂定）：**Accord: Perfume Formula Lab**　　用户 2026-11-26 点名（五个 App 之二，排在 Groovelens 之后）

## 1. 一句话定位
自己在家调香的人（DIY 调香、香薰蜡烛、手工皂），在工作台前用它记配方、按克数/滴数/百分比互换、稀释和放大批量，并看到这支香「几小时后闻起来是什么样」。

## 2. 差异化楔子
用户为什么选我而不是 Formulair（$39.99，★4.8/199，2024 年后近乎停更，仅英文）/ Ffragrance（$7.99）/ Perfumers Vault（PRO $4.99–39.99）：**唯一 10 种语言、iPhone 原生设计（竞品几乎全是英文 + iPad 界面缩放），配方一屏完成克/滴/% 互换与稀释折算，外加按真实配比画出的挥发时间轴；买断价只有 Formulair 的四分之一。**

## 4. 核心循环与功能清单
核心循环：新建配方 → 加原料（克/滴/%，可标「10% 稀释液」）→ 实时看到纯料百分比、总浓度、挥发时间轴 → 存成版本 → 放大批量去称料 → 熟成日记记气味变化 → 改出 v2。

| 功能 | 免费 | Pro |
|---|---|---|
| 配方编辑：克 / 滴 / 百分比三种单位任意输入，其余两种自动算 | ✓ | ✓ |
| 稀释液折算（原料标 1% / 10% / 自定，自动拆成纯料 + 溶剂） | ✓ | ✓ |
| 挥发时间轴（招牌图） | ✓ | ✓ |
| 配方数量 | 5 个 | 无限 |
| 批量放大：输入目标总量 + 目标浓度（EdT 10% / EdP 20% / Extrait 30% / 蜡烛 8% / 自定） | 预览 | 完整称料单 |
| 版本对比（v1 vs v2 差在哪几个料、几个百分点） | — | ✓ |
| 熟成日记（第 1/7/14/28 天气味笔记 + 提醒） | — | ✓ |
| 原料库存（剩余克数、每克成本 → 每瓶成本） | — | ✓ |
| 用户自填的单料上限（%）提醒 | ✓ | ✓ |
| 导出称料单 PDF / CSV | — | ✓ |

**刻意不做**：不内置 IFRA 限量数据库、不内置香料百科（纪律 AD：内容授权门槛，服务端也解不开）。上限由用户自己填，App 只负责提醒；介绍页写明「请以你的供应商 SDS / IFRA 文件为准」。

## 5. 页面
1. **工作台（首屏）**：当前配方本身。顶部挥发时间轴，下面原料行（名称 · 香调层 · 数值 · 单位切换），底部拇指区「加原料」「称料」。冷启动直接打开示范配方「Bergamot Cologne」，0 次点击见结果。
2. **配方架**：所有配方的瓶子缩略（每瓶的颜色条 = 该配方前中后调比例）。
3. **称料单**：放大批量后的逐行清单，可逐行勾选「已称」，大字号、防手湿误触。
4. **熟成日记**（Pro）：时间线 + 每条笔记。
5. **原料库**：用户自建原料（香调层、默认稀释度、上限、库存、成本）。
6. **设置**：App 内语言切换（10 种，立即生效）、单位（滴/克换算系数，默认 1 g ≈ 20 滴可改）、恢复购买、隐私、支持。

## 6. 招牌功能架构
- **换算引擎**（纯函数，可单测）：输入每行 `(数值, 单位, 稀释度)` → 输出纯料克数、溶液克数、纯料 %、溶剂总量；滴↔克用用户可改的系数；舍入只在显示层做，存储用 Double 全精度。
- **挥发时间轴**：按每个原料的香调层（top/heart/base，用户可改）给半衰期假设（top ≈ 0.5 h、heart ≈ 3 h、base ≈ 24 h，**这是示意模型，界面写明「示意」**），把纯料克数 × 衰减曲线叠加，画出 0–24 h 每层占比的堆叠流图。数据真实（来自配方），模型简单透明。
- **批量放大**：目标总量 × 目标浓度 → 每个纯料克数 → 再按该原料常用稀释度折回溶液克数。
- 存储：SwiftData（Formula / FormulaLine / Material / Batch / AgingNote），版本 = 复制 Formula 并记 parentID。

## 9. 设计简报
| 项 | 决定 |
|---|---|
| 色相 | **琥珀 52°**（色相表空档黄 50–65°；不撞 goldenscout 37°）。意象：调香台上的琥珀色精油瓶、牛皮纸标签、黄铜秤 |
| 色彩（浅） | 纸 `#F6F1E7` · 墨 `#2A2420` · 琥珀 `#C8941E`（强调，≤10%）· 前调 `#9DB8A0`（佛手柑绿）· 中调 `#C98B9B`（玫瑰）· 后调 `#7A5A44`（檀木） |
| 色彩（深） | 夜 `#1C1916` · 纸灰 `#E9E2D4` · 琥珀 `#E0AE3C` · 三层调色同色相提亮 |
| 字体 | 展示：**Bodoni Moda**（OFL，只打包 600/700 italic）；数字：系统等宽数字（SF Mono digits）；中日韩正文系统字体，展示字体在 CJK 下回退系统 Serif |
| 形状 | 圆角只有 3 个：4（标签/输入）· 12（行）· 28（底部主按钮） |
| 密度 | 基准 8pt；行高 1.35；原料行 56pt |
| 图形语言 | **挥发时间轴**：横轴 0→24 h，三层调色堆叠流图，随配方实时变化；配方架上每个瓶子是它的缩略。牛皮纸标签式的原料名条 |
| 质感 | 纸张颗粒噪点 3%；无渐变卡片、无霓虹；动效以「液面上升」「标签滑入」为主，尊重减少动态效果 |

## 12. 真机验收清单
1. 冷启动直接看到示范配方和时间轴。
2. 把一行从「克」切到「滴」再切到「%」，其余行与总浓度同步变。
3. 把佛手柑标成 10% 稀释，纯料 % 正确下降。
4. 放大到 50 ml EdP，称料单数值合理、可逐行勾选。
5. 建第 6 个配方弹付费页，价格是商店真实价格；恢复购买可用。
6. 设置里切日文，整个 App 立即变日文。
