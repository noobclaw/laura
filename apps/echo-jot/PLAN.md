# 回声笔记 EchoJot — 产品规划文档

> 状态:🟢在做(2026-07-30 工厂日取项攻关) · 立项 2026-07-09 · 来源:BACKLOG #2(指数 83,缺口 15/15 + 付费 19/25,队列唯一同时过双硬门项)
> 一句话:**点一下就说、边说边出字的离线语音笔记——声音不出这台手机,也不留录音。**

## 0. 本轮(2026-07-30)取项与技术攻关结论

**取项**:BACKLOG ⚪排队各项连续第 3 轮无一同时过「缺口 ≥5/15 且付费验证 ≥15/25」双硬门(#5 胶片缺口 0、#9 Orbit 付费 14、#10 Swing Trace 缺口 3、#11 照片恢复双项不过),本项是唯一过双硬门的高分项,仅因**技术阻塞**卡在 🟢在做 → 本轮工厂 = 攻关 + 落地。

**原阻塞**:`whisper_flutter_new` 运行时从 HuggingFace 下模型(违背「零 INTERNET 权限」),自带 60MB 权重则要本机验 NDK 构建(8GB 机器做不到)。

**攻关结论(采纳 Show HN `Yap` 范式)**:**不自带、不下载任何模型,直接调系统内置的设备端语音识别。** Android 12(API 31)起 `SpeechRecognizer.createOnDeviceSpeechRecognizer()` + `isOnDeviceRecognitionAvailable()` 是**契约级的设备端**识别,无权重、无下载、无网络权限,卖点完整保留。实现是本 app 自己的 Kotlin 桥(`android/app/src/main/kotlin/com/noobclaw/echojot/DictationBridge.kt`),**不引入第三方语音插件**(前几轮的构建事故都来自插件版本错位)。

**由此产生的产品变更(已拍板,写进本文档)**:系统识别器**只能边说边听、不能读取已保存的音频文件** → 产品从「录完再转写」改为「**边说边出字的听写**」,并且**完全不保存音频文件**。这不是缩水:①「没有录音可泄露」比「录音只存本地」隐私更硬 ②原 v2 里的「实时边说边出字」提前到 v1 ③代价是砍掉音频回放(v1 明确不做)。

## 1. 定位与人群

- **解决什么**:走路/开车/开会时冒出的想法,打字来不及;云端转写 app 要订阅、还把录音上传。回声笔记点一下就说,文字边说边出,全程在这台手机上。
- **目标用户**:①随时记想法的创作者/产品人 ②隐私敏感者(律师/医生/记者) ③讨厌订阅制的工具党。
- **⭐ 差异化楔子(一句话)**:**「同类里唯一一个:一次买断、零网络权限、连录音文件都不留——而且它做得到,是因为它用你手机系统自带的设备端识别,不是把你的声音送上云。」**
- 竞品对照:

| 竞品 | 弱点 | 我们 |
|---|---|---|
| Otter / 讯飞听见等云端转写 | 订阅 $10+/月;录音上传云端 | 一次买断;零网络权限;不存录音 |
| 系统备忘录 / 录音机 | 无转写或需在线;搜不到语音内容 | 离线转写 + 全文搜索 |
| Just Press Record($4.99 买断) | iOS/watchOS 独占;转写走系统在线识别 | Android 首发;只用**设备端**识别并可在应用内自证 |
| Yap / FluidVoice(桌面开源) | 只有桌面端 | 移动端空位正是我们的 |

- **卖点文案**:「你的声音不出这台手机」——app 不申请网络权限(manifest 里 `INTERNET` 被 `tools:node="remove"` 显式剥离),商店审核与用户都可验证。

## 4. 技术方案(G2 招牌功能架构评审)

**招牌功能 = 「离线听写必须真的离线、且真的能出字」**,机制选型定死如下:

| 关注点 | 选型 | 为什么不是别的 |
|---|---|---|
| 转写引擎 | 系统 `SpeechRecognizer.createOnDeviceSpeechRecognizer`(API 31+),`EXTRA_PREFER_OFFLINE=true` 双保险 | whisper 插件运行时下权重(破零联网);自带权重需 NDK 本机验不了;**普通 `createSpeechRecognizer` 可能走云,一律不用** |
| 最低版本 | `minSdk = 31` | API 31 以下没有「保证设备端」的 API,只能云端兜底 → 宁可不上,不做假承诺 |
| 长段落 | 桥内**重启循环**:`onResults`/良性 `ERROR_NO_MATCH`/`ERROR_SPEECH_TIMEOUT` → 立刻重新 `startListening`;每段作为 `final` 事件拼接 | 系统识别器一次只认一个 utterance;不重启就只能记一句 |
| 失败兜底 | 非良性错误重建识别器,连续 4 次无结果 → 停止并弹可见错误 | 防止无声无息的死循环(闹钟教训:静默失败=功能不成立) |
| 线程 | 所有 `SpeechRecognizer` 调用 post 到 main looper | 该类是主线程 only,否则 OEM 上随机崩 |
| 权限 | `permission_handler` 显式请求;拒绝→提示;永久拒绝→`openAppSettings()`;Kotlin 侧再 `checkSelfPermission` 兜底 | 禁止静默失败(G2 硬要求) |
| 后台 | **不做后台听写**:`AppLifecycleState.paused` 即结束并保存,并明确告知 | 系统识别器是前台设施,Doze/OEM 后台管理下不可靠;不假装 |
| 音频 | 不落地任何音频文件;旧版残留 `audio/` 目录首启即清理 | 系统识别器不返回音频;不存录音本身就是卖点 |
| 标点 | 纯 Dart 本地规则(`transcript_text.dart`,单测) | 系统识别器通常不给标点;不引入云端 LLM 补标点 |
| 存储 | 单 JSON(`notes.json`,含 `pro` 标志),沙箱内 | 千条量级足够,免数据库依赖 |
| 计费 | 真 `in_app_purchase`(`pro_unlock` 非消耗品)+ 恢复购买;结算走 Play 进程,**不需要 INTERNET** | Play 政策强制;与零联网卖点不冲突 |

**语种诚实标注**:能识别哪些语言取决于**用户系统里装了哪些设备端语言包**,不是应用自带。设置页「设备端识别状态」直接展示 `checkRecognitionSupport`(API 33+)报告的已装语言;API 31/32 无法枚举时只说「使用系统已安装的语言包」,不吹。

**风险与对策**
| 风险 | 对策 |
|---|---|
| OEM 无设备端语言包 | 首页横幅 + 设置页状态 + 「重新检测」;停止听写,**不联网兜底** |
| 系统识别器标点/长句弱于 whisper | 本地规则补句读;详情页编辑是一等公民 |
| OEM 识别器实现古怪(busy/client 错误) | 重建识别器重试,4 次仍无果 → 可见错误 |
| Android 12 以下装不了 | 明确写进商店说明;iOS 版排 v2 覆盖另一半市场 |
| 免费/Pro 闸门 | 真 Billing 已接;上架前须走内部测试轨验「购买→解锁→卸载重装→恢复」 |

## 7. 真机验收清单(装机后照着点,任一不过即打回)

1. **首启**:打开 app → 首页出现「说出第一条笔记」空状态 + 底部大话筒按钮(深浅色各看一次)。
2. **权限**:第一次点话筒 → 弹系统麦克风权限框;**点「拒绝」→ 必须出现可见提示**(不是没反应);再点一次并允许 → 进入听写态。
3. **设备端识别可用性**:若首页出现橙色横幅(无设备端识别),按提示到「系统设置 → 系统 → 语言与输入法 → 设备端语音识别」下载中文/英文语言包,回到 app 点「重新检测」→ 横幅消失。
4. **核心功能:边说边出字**——说一句中文(如「明天上午十点去银行取钱」),**说的过程中文本框就该出现文字**;停 2 秒再说第二句,两句应拼成一条笔记(第一句结尾自动补「。」)。
5. **停止与保存**:点停止 → 时间线顶部出现新卡片,标题=首句、时长与字数正确。
6. **英文**:切系统语言到 English(或装英文语言包后说英文)→ 句首自动大写、句间空格正确。
6b. **深色模式 + 听写态外观**(CI 截不到,必须人眼看):系统切深色 → 话筒按钮图标清晰可见(不是灰白糊成一片)、面板边缘可见;听写中电平条静息是一排圆点、说话时铺满面板宽度、脉冲光环是完整圆(不是平顶)。
7. **不留录音**:说完后到系统文件管理/应用存储里确认没有音频文件(应用目录只有 `notes.json`)。
8. **飞行模式**:开飞行模式(或关 WiFi/数据)→ 听写仍然可用(这是卖点,必须验)。
9. **编辑与分享**:点卡片改几个字 → 返回再进,改动仍在;分享给微信/记事本能收到文字。
10. **切后台**:听写中按 Home → 回来时应显示「应用切到后台,听写已结束并保存」,且刚说的内容已存成笔记(不该有半截丢失)。
11. **删除**:左滑删除一条 → 列表刷新,重启 app 后仍是删除后的状态。
12. **搜索**:攒够 5 条以上笔记 → 搜索框出现,输关键词能过滤。
13. **免费/Pro 闸门**(可选,费时):攒到 30 条后再点话筒 → 弹解锁面板;点「恢复购买」不崩(未上架时提示商店不可用属正常)。
14. **边界**:①一句话不说直接停止 → 提示「没听到内容,这条没有保存」 ②插拔耳机/来电打断听写 → 有可见提示或正常结束,不卡死。
