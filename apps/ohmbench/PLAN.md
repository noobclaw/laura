## 一、一句话定位

手机和平板上**算得对、编得动、丢不了**的电路仿真台:画一张原理图,立刻看到每个节点的电压、每条支路的电流和示波器波形,全程离线、一次买断。

## 二、差异化楔子(「用户为什么选我而不是 iCircuit / CRUMB」)

**在位者的差评收敛到四件事,而这四件事没有一支在商店描述里承诺过。**(6 支在位者描述今日全读,见 §三)

> **别的电路 app 会跟你打架、会丢你的作品、要联网、买了还有广告;OhmBench 不会 —— 它没有网络权限,所以它做不到。**

四条腿,按**可证伪程度**排序(这是本轮对楔子的重要修正,见 §三 3):

| # | 楔子 | 证据(用户原话) | 可证伪性 |

## 四、架构评审(招牌功能的可靠性机制,写码前定死)

| 机制 | 选型 | 为什么不是另一种 |
|---|---|---|
| 数值引擎 | **改进节点法(MNA)+ 牛顿迭代 + 梯形积分**,稠密 LU + 部分选主元 | 手机电路规模是几十个未知数,稠密 n³/3 在 n=60 约 7 万次浮点 = 远低于一帧;稀疏排序(SpiceSharp 的 Markowitz)留到 M3 且只在实测需要时做 |
| 非线性收敛 | **限压(`DEVpnjlim`)+ gmin 阶梯 + 源阶梯**三级兜底,全用 SPICE 默认容差 | 只有牛顿 = 二极管一次坏猜测就 `exp` 溢出;三级兜底是 SPICE 四十年的答案,不自创 |
| 拓扑→网表 | **并查集**,以「点落在线段上即连通」为规则(T 型接点自动成立) | 只认端点相连 = 用户必须精确命中端点,正是「触屏编辑打架」的病灶 |
| 坐标 | **整数栅格**,落点即吸附,绝不存浮点坐标 | 浮点坐标 = 「看起来连上了其实差 0.3 格」,这类静默失败最难被用户理解 |
| 撤销 | **整文档快照栈**(上限 512 步) | 逆操作栈是「撤销把电路搞坏了」这类 bug 的老家;一张手机尺寸的图几 KB,快照更便宜也更安全 |
| 存盘 | 壳的 `JsonFileStore`:临时文件 + 原子 rename;解析失败**改名留档**不覆盖 | 用户唯一一份作品,不接受「写一半崩了」 |
| 实时仿真 | 开关用**电导**建模(闭合 1mΩ / 断开 1TΩ),拨动不改变矩阵结构 | 改结构 = 每次拨开关重建矩阵并可能丢收敛历史 |
| 网络 | **无 INTERNET 权限**(壳默认 `tools:node="remove"`) | 楔子③ 就是这条;有权限就不可证伪 |

**服务端:无。** 本项不使用 `256btc.com`,无同步、无云端、无账号 → 离线降级问题不存在,App Store 数据收集声明填「不收集」。

**危险权限:无。** 不用相机/麦克风/定位/通知。iOS 侧因此**不需要任何 `NS*UsageDescription`**,也**不得**提交 `ios/Podfile`(PIPELINE iOS 铁律②)。

**iPad:M1 不发。** 本候选在 BACKLOG 里写的是「iPhone/iPad 电路仿真」,且 Reddit 信号最新一条来自 `r/iPadPro`,`CRUMB`/`iCircuit 3D` 都是 iPad 主场。但按 PIPELINE「iOS 只发 iPhone(`TARGETED_DEVICE_FAMILY = 1`)」,发 iPad 就必须另做布局 + 13 吋截图,拉伸充数会撞 2.3.3。**决定:M1 iPhone-only,iPad 作为 M2 的第一项**(那时画布/工具栏要重新排版,不是加个 flag)。此事**写进 M2 验收**,别在 M1 悄悄打开。

## 六、引擎误差门限(写死在测试里,G2 已达成)

`flutter test` 50 条全绿(引擎 22 / 图纸 27 / 壳 1)。门限与**今日实测值**:

| 场景 | 门限 | 实测 | 对照方法 |
|---|---|---|---|
| 线性 DC(分压/并联/电桥/串联源) | 相对 1e-9 | 精确到 1e-12 | 手算闭式解 |
| 二极管工作点(电压) | ≤ **1e-5 V** | **3.4e-6 V** | **独立二分法**解同一 Shockley 方程(与被测代码零共用) |
| 二极管电流 | ≤ 1e-3 相对 | 1.3e-4 | 同上(电流对电压指数敏感,dI/I = dV/Vte) |
| RC / RL 阶跃(h = τ/100) | 摆幅的 0.5% | <0.5% | 解析 `1-e^{-t/τ}` |
| LC 谐振(3 个周期) | 幅度漂移 ≤1%、周期误差 ≤0.5% | 均满足 | 解析 `1/(2π√LC)` |
| 半波整流 / 二极管钳位 | 正峰 = 输入 −0.7V ±0.25V;负半周不跟随 | 满足 | 定性 + 边界 |
| 不收敛 / 奇异 | **一个数都不报**,返回 `didNotConverge` / `singular` | 满足 | 两源并联不同电压 |
| 悬空元件 | 仍出解,并标 `floatingNodesTiedToGround` | 满足 | 1GΩ 对地兜底 |

**⚠️ 仍欠一条(M2 补):与 `ngspice` 的交叉对账。** 现在的对照全是闭式解与独立二分法 —— 已经能挡住算错,但**挡不住「模型选错」**(例如二极管温度系数、电容初值语义)。M2 要在开发机装 `ngspice`,导出 `.cir` 跑同一批电路,把标准答案抄进测试。
