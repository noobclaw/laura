## 七个 app 共用的病（修壳一次七个都好）

1. **iOS 从来没人审过**：G3/G5 只看 Android。plist key 漏 3 个、权限宏没开、显示名无本地化、echo-jot 语音只有 Kotlin 桥、daycount 小组件只有 Android、fieldstamp 缺 `NSPhotoLibraryAddUsageDescription`、iPad 分享全崩。→ PIPELINE 已加「iOS 平行检查」。
2. **存盘不原子、损坏即清空**：remcard（已修）/ daycount / fieldstamp / autosnore。remcard 的修法应下沉到壳。
3. **内购反馈只在设置页**：5 个 app 从首页 / Pro 弹层 / 报告页购买全静默。`PurchaseNotices` 应挂到根。
4. **跨零点不刷新**：daycount / remcard / goldenscout 日期只在 build 时算一次。
5. **罗盘语义三种错法**：fieldstamp / goldenscout / orbit 磁北真北不一致、无磁偏角、iOS 未授权 −1 被当有效、orbit 机顶 vs 机背差 180°。
6. **验收清单跑在代码前面**：remcard 清单要求看到到期日变长（UI 无处显示）；fieldstamp 清单要求「去系统设置」出口（全仓 0 处 `openAppSettings`）。
