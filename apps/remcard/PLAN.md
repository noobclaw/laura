## 1. 定位与人群

- **解决什么**:背单词/考点/术语靠死记效率低;Anki 强大但界面陈旧、$29.99 劝退新手,云端记忆 app 又要订阅+上传数据。Remcard 用经典 SM-2 间隔重复算法安排复习,纯本地、无账号、无订阅。
- **目标用户**:①备考族(语言/证书/医学术语) ②终身学习者 ③讨厌订阅、注重隐私的工具党。
- **差异化(vs 竞品)**:

| 竞品 | 弱点 | 我们 |
|---|---|---|
| AnkiMobile | 界面陈旧、$29.99 门槛、上手陡 | 现代 Material 3、$4.99 买断、开箱即用 |
| 云端记忆 app(Quizlet 等) | 订阅制、卡片上云 | 一次买断、零网络权限 |
| 系统备忘/笔记 | 无科学复习调度 | SM-2 到期提醒式复习 |

- **卖点文案**:「你的记忆,离线安排」——app 不申请网络权限,商店审核可验证。

## 2. 功能清单

**v1(本次交付,核心闭环)**
- [x] 牌组(Deck):新建/改名/删除;卡片计数 + 今日到期数徽章
- [x] 卡片(Card):正面(问题)/背面(答案)增删改
- [x] 复习会话:按 SM-2 取今日到期卡 → 点卡翻面看答案 → 4 档评分(重来/困难/良好/简单)→ 算法更新间隔与到期日
- [x] 复习进度指示(本轮剩余张数)、无到期卡时空状态引导
- [x] 全本地 JSON 持久化(文档目录),即时保存
- [x] 设置:SM-2 原理说明 + 隐私声明(零网络)
- [x] 免费额度门(免费 2 个牌组,满后引导解锁 Pro;v1 为本地开关,IAP 接入在上架前完成)

**v2(上架后迭代,不阻塞 v1)**
- 备份导出/导入(zip 到分享面板)· 富文本/图片卡面 · 每日提醒通知 · 统计图表(记忆曲线/正确率)· CSV 批量导入 · 桌面小组件今日待复习

**明确不做**:云同步、账号系统、协作、社区共享牌组——违背零服务端定位。

## 3. 页面结构与交互

```
主屏(牌组列表 + 右下「新建牌组」FAB)
 ├─ 点牌组 → 牌组详情(卡片列表 · 顶部「开始复习(N 张到期)」按钮 · FAB 加卡)
 │    ├─ 点卡片 → 卡片编辑(正面/背面)
 │    └─ 长按/滑动 → 删除卡片
 ├─ 复习按钮 → 复习会话(卡面正面 → 点击翻面 → 4 档评分 → 下一张 → 完成)
 └─ 右上设置 → 设置页(壳自带:隐私/关于 + 本 app:SM-2 说明/解锁 Pro)
```

## 4. 技术方案

- **壳**:tool_shell 母版,`RemcardTool implements ToolModule`。
- **算法**:经典 **SM-2**(SuperMemo 2)纯 Dart 确定性实现:`ease`(默认 2.5,下限 1.3)、`interval`、`repetitions`;4 档评分映射 quality。到期日 = 今日 + interval(天)。**有单元测试覆盖调度正确性**。
- **存储**:牌组+卡片序列化为单个 JSON 文件,`path_provider` 取文档目录;千级卡片量内存操作足够。
- **权限**:无。**AndroidManifest 不含 INTERNET**——沿用壳的零网络承诺。
- **依赖**:仅 `path_provider`(存储)。无原生编译、无网络、无三方 SDK ⇒ CI 构建风险极低,本机可 `flutter analyze` + `flutter test` 全验。

**风险与对策**
| 风险 | 对策 |
|---|---|
| SM-2 调度算法写错 | 纯函数 + 单元测试(again 归零重学 / 简单拉长间隔 / ease 下限 1.3) |
| 卡片多时列表卡顿 | ListView.builder 懒构建;千级足够 |
| IAP 未接阻塞收费 | v1 本地闸门+牌组计数,上架前接 in_app_purchase(产品 ID `pro_unlock`) |

## 4b. v1.1/v1.2 路线(2026-08-30 竞品实查后定,用户拍板「v1 先占坑、导入随更新走」)

> 实查结论:**「全手动建卡」的间隔重复 app 在市场上已不存在**,头部竞品各修了一条「内容从哪来」的路——现成牌组库(Noji「5 万现成牌组」★4.57/1.4 万条、Brainscape ★4.76/2.1 万条)、从别家导入(SmartCards+ 第一卖点「Don't start from scratch,从 Anki/Quizlet 导入」★4.57/2297 条)、AI 生成(AlgoApp「PDF 转闪卡」★4.67/2 万条、Quizlet ★4.78/110 万条)、笔记转卡(Mochi/RemNote)。另:AnkiMobile 本体仅 ★4.04/2319 条,护城河在桌面生态非 app 本身。「录卡太累」是品类公认第一门槛,v1 一条路都没修,**不阻塞首发,但 v1.1 必须补**。

- **v1.1 粘贴/CSV 批量导入 + 导出备份**(纯本地,~1-2 天):粘贴或选文件,每行「正面,分隔符,背面」一次进几百张;同时补导出(JSON/CSV)——同品类差评第二大点就是「丢数据/无导出」(08-28 纪律 AF 实查)。
- **v1.2 `.apkg` 导入**(zip+sqlite 解析,开发量中等,零联网可行):直接吃 Anki 牌组格式 → AnkiWeb 数万个免费共享牌组全部变成可用内容,零内容运营;与「$4.99 vs AnkiMobile $24.99」楔子指向同一批用户(嫌 Anki 贵的人手里全是 .apkg)。
- **不做**:牌组社区(要服务端)、AI 生成卡片(要联网,砸零联网卖点)。

## 7. 真机验收清单（G7，请照着点）

> 原第 6 节里程碑表的 M3 只有一行「全流程 OK」，不可执行。此节为 G7 要求的逐条清单。
> 每条只有两种结果：✅ 过 / ⛔ 挂（挂的写一句现象）。任一条 ⛔ 则本 app 不进 G8 上架。

1. **首启空状态**：不是一行冷字——有图标 + 引导 + 「新建牌组」入口。
2. **🔴 核心闭环（必验）**：建牌组 → 加 5 张卡 → 进入复习 → 四档评分各点一次 → 全部复习完有完成态，不卡死、不重复出同一张。
3. **🔴 SM-2 调度真的在算**：对同一张卡点「**重来**」→ 它应**马上或很快再出现**；点「**简单**」→ 下次到期日应明显更远（在卡片详情或牌组进度里能看到到期日变长）。**这是本 app 的招牌，调度不对等于产品不成立。**
4. **跨天到期**：今天复习完 → **明天再打开**（或临时改系统日期到明天）→ 应出现今天该到期的那批卡，数量对得上。
5. **免费门**：免费可建 **2 个**牌组、卡片无限；建**第 3 个**牌组时被挡并弹购买页。
6. **真内购全流程**：购买 → 解锁无限牌组 → **卸载重装** → 「恢复购买」→ 仍是 Pro。价格是商店下发的本地价，不是写死的 ¥18。
   - ⚠️ 本 app 用的是历史遗留的裸商品 ID `pro_unlock`（其余 app 已改成 `<applicationId>.pro_unlock`），两店保持不变——验收时确认**商店后台建的商品 ID 与代码一致**，否则购买会直接失败。
7. **数据不丢**：杀进程重开 → 牌组、卡片、复习进度全在。
8. **深浅色**：两套各看一遍牌组列表/复习页/统计，评分按钮配色在深色下不刺眼。
