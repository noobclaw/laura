## 新引入的问题(🔴/🟠/🟡)

**N1 🟠 `import_flow.dart:81-85` + `:101 / :105 / :114` — Android 返回键会把「正在读取」对话框弹掉,随后的 `navigator.pop()` 弹错栈**
`barrierDismissible:false` 只挡点遮罩,不挡系统返回;对话框没有 `PopScope(canPop:false)`。解析中用户按返回 → 对话框先没了 → 解析结束时无条件 `navigator.pop()` 弹的是它下面那个路由。从首页 `_ImportRow` / 空状态按钮发起导入时,下面就是根路由 → 根路由被弹掉,app 变黑屏,只能杀进程;从设置页发起则设置页被弹回首页,预览框接着弹在首页上。触发概率不低:大包解析期间转圈是冻住的(见 N3),用户会以为卡死而按返回。
修法:`_ParsingDialog` 外包 `PopScope(canPop:false)`;并且不要用外层 `navigator.pop()`,改成拿对话框自己的 context(builder 里存下)`if (ModalRoute.of(dlgCtx)?.isCurrent == true) Navigator.of(dlgCtx).pop()`,或 `navigator.removeRoute(route)`。

**N2 🟠 `study_screen.dart:57-69` + `models.dart:99-107` — 重来卡第二遍评分仍跑完整 SM-2,一场里错三次 ease 永久打到地板**
(a) 同一张卡本轮 Again→Again→Again:每次 `ease -= 0.54`(q=1),2.5 → 1.3 地板,而之后 Good 不涨、Easy 每次只 +0.1,这张卡此后几个月间隔都被压扁——首轮 Y2 的问题被 O2 的实现放大了一个数量级。(b) Again 后几分钟再见到,按钮上写着「简单 · 4 天」诱导点它 → `repetitions` 已归 0,`previewInterval(easy)=4`,一张刚答错的卡直接 4 天后见(Anki 的 relearn 无论怎么评都是 1 天)。完成页文案「明天再来一遍」此时也不对。
修法(即首轮 O2-A 原话):重现时(`_seen.contains(card.id)`)评分 ≥困难 → 只从队列移除,不调 `reviewCard`(第一次 Again 已把 dueDay 设为明天);再次 Again → 只 `_lapses++` 并重新入队,同样不调 `review`。重现卡的三个按钮小字统一显示「明天」。顺手改 `remcard_tool.dart:611/624` 原理页文案。

**N3 🟡 `import_flow.dart:90-99`、`apkg_import.dart` 全部 — 解析在 UI isolate 同步跑,转圈冻住**
`ZipDecoder.decodeStream`、`readBytes()` 解压整个 SQLite、`_readCollection` 逐行 `htmlToPlainText`、CSV `parseDelimitedCards` 全是同步;只有 `getTemporaryDirectory()`/`readAsBytes()` 两个 await 让对话框有机会画出第一帧,之后 `CircularProgressIndicator` 静止数秒(代码注释自己写了「20k 卡要几秒」)。Dart UI isolate 卡住不会触发 Android ANR,但配合 N1 会让用户按返回。修法:`Isolate.run(() => readApkg(...))` / `Isolate.run(() => parseDelimitedCards(...))`,纯 Dart + sqlite3 ffi 在 isolate 里都能跑,`ImportException` 可跨 isolate 抛回。

**N4 🟡 `apkg_import.dart:37,59-67` — 文件句柄泄漏 + 大包双倍内存 + picker 缓存不清**
`InputFileStream(path)` 打开的 `RandomAccessFile` 从未 `close()`(archive 4.2.0 有 `InputFileStream.close()`),每导一次漏一个 fd。`dbEntry.readBytes()` 把整个 `collection.anki21`(大共享牌组几十 MB)解压进内存再 `writeAsBytes`,峰值约 2× DB;可改 `dbEntry.writeContent(OutputFileStream(tmpPath))` 流式落盘。另 file_picker 会把选中的文件整份复制到 app cache(Android)/tmp(iOS),流程结束没调 `FilePicker.platform.clearTemporaryFiles()`,300 MB 的 apkg 就留在缓存里。sqlite 部分本身没问题:`OpenMode.readOnly` ✅、`finally db.dispose()` ✅、临时 DB `finally delete` ✅。

**N5 🟡 `import_flow.dart:91` — 只按文件名后缀判格式,二进制文件会「成功」导出垃圾卡**
`.colpkg`、被改名的 apkg、或 `FileType.any` 下误选的 PDF/图片都走文本路径:`utf8.decode(allowMalformed)` → `detectDelimiter` → 二进制里凑够两个非空「列」就是一张卡 → 预览里显示乱码卡(用户能取消,但手快就导进去了)。修法:先嗅 zip 魔数 `50 4B 03 04` 决定走 apkg 路径;文本路径若 U+FFFD/控制字符占比高直接判 `unreadable`。

**N6 🟡 `import_flow.dart:118-126` — 预览框名字留空点「导入」静默无事**
`name.trim().isEmpty → return`:对话框关了、牌组没建、没有任何提示。按 `_cardEditor` 的做法给 `TextField` 加 `errorText` 并保持打开。

**N7 🟡 `store.dart:127-144` — 首轮 Y8 后半段仍开着**:导入 2000 张全部今天到期,首页 hero 第一天就是「2000」。无每日新卡上限。产品决定,记录为未做。

**N8 🟡 壳层 `purchase.dart:152-173` `restore()` 的 5 秒是盲等**:iOS 若弹 Apple ID 登录、用户输密码超过 5 秒,会先看到「没有找到可恢复的购买」再看到「已恢复 Pro」两条自相矛盾的提示;5 秒内点两次恢复,第二次把 `_restoreDelivered` 清零可能让第一次误报「没找到」。不阻断。

**N9 🟡** `tr()` 覆盖:逐文件核对新增代码,用户可见字符串无漏 `tr()`;`formatLabel`('TSV'/'CSV (;)'/'Anki')是格式名不算;`unreadable` 分支把原始异常 `$e` 拼给用户(`import_flow.dart:109`),英文技术串,可接受。

未发现空安全或 dispose 问题:`_PreviewDialogState` 正确 dispose 控制器;`import_flow` 每个 await 后都有 `context.mounted` 检查(`messenger`/`navigator` 提前捕获);`_grade` 双击安全(setState 同步推进);`file_picker` 在 iOS/Android 未传 `withData/withReadStream`,`path` 非空成立(:71 兜底也在)。Pro 门:导入在开 picker 前查 `atDeckLimit`(`remcard_tool.dart:211`),预览是模态,无并发绕过路径。
