# Art Bible：貓躲狗找

全部美術由程式生成（網格、著色器、貼圖、音效），不用下載的素材檔。字型例外：Noto Sans TC／JP（OFL）。

## 1. Visual Identity Statement

午後陽光斜照進來的日式老家，像一本立體繪本：圓潤、溫暖、東西很多，但每樣東西都認得出來。

## 2. Mood & Atmosphere

- 白天：暖色主光從緣側斜射進來，室內有明顯的光斑和柔和的陰影，空氣裡有灰塵。
- 夜晚模式：只有檯燈、電視和手電筒，冷暗底色加暖色小光源。
- 整體安靜可愛，緊張感來自玩法，不來自畫面。

## 3. Shape Language

- 貓：圓、軟，沒有尖角。頭身比約 1:1.5。
- 狗：比貓方、比貓大一圈，輪廓更有稜角，一眼分得出陣營。
- 家具：倒角的方塊，邊緣略圓，比例略胖。
- 禁止：裸露的引擎預設方塊和球、銳利的 90 度邊、純平面無厚度的物件。

## 4. Color System

| 用途 | 顏色 |
|---|---|
| 木頭 | 蜂蜜色 #C89B5E、深褐 #6B4A2E |
| 榻榻米 | 草綠偏黃 #B9B274 |
| 牆 | 米白 #EFE6D3 |
| 布料重點色 | 靛藍 #2F4B7C、朱紅 #C8452E、芥末黃 #D9A93A、抹茶綠 #7A9A54 |
| 貓隊 UI | 暖橘 #F29A4A |
| 狗隊 UI | 天藍 #4AA3E0 |
| 揭曉高亮 | 沒被找到＝紅，被找到＝藍（照原作慣例） |

場景顏色要多而且分區明確，這樣塗色才有挑戰也有成就感。同一個房間裡至少 12 種明顯不同的顏色。

色盲：陣營與揭曉狀態除了顏色還要有圖示（貓掌／狗掌、圈／叉）。

## 5. Character Design Direction

- 未塗色的貓是啞光白，眼睛、鼻子、肉球是固定的小細節（不可塗），其餘全身可塗。
- 貓狗都是參數化模型：體長、腿長、胖瘦、耳型、尾型、口吻長度。
- 表情用眼睛形狀和耳朵角度表達，不做嘴型動畫。
- 全部原創造型，不參考任何有版權的卡通角色。

## 6. Environment Design Language

- 每個鏡頭三層：前景遮擋物、中景家具、遠景牆面與窗外。
- 表面都有程式貼圖：木紋有年輪方向，榻榻米有編織紋和布邊，布料有織紋，紙門有纖維。
- 接觸陰影（物件底部變暗）一定要有，東西才不會像浮著。
- 窗外不是空的：院子、圍籬、遠處屋頂、天空漸層。

## 7. UI/HUD Visual Direction

- 用 HTML/CSS 做，不用引擎內建的除錯介面樣式。
- 風格：和紙質感的面板、圓角、手寫感標題配清楚的黑體內文、貓掌狗掌圖示。
- 頂部：階段名稱、倒數、雙方存活圖示。底部：狗顯示球數，貓顯示姿勢與分身冷卻。
- 版面自己設計，不照原作的排法。
- 字一律程式排版，支援繁中、日文、英文切換。

## 8. Asset Standards

- 一隻貓的三角面 ≤ 6k，塗色貼圖 512²；整個場景同屏 ≤ 60 萬三角面，繪製呼叫 ≤ 300（用實例化與合併）【目標值，未實測】。
- 所有隨機用固定種子，同一張圖每個人看到的一樣。
- 後處理順序：環境光遮蔽（或烘焙接觸陰影）→ 泛光 → 色調映射 → 調色 → 暗角。低配可逐項關閉。
- 每個物件登記在 entity-inventory.md。

## 交付前自查

把截圖和 Starfall 的截圖並排。逐條對：真 3D 光影、環境完整、模型有細節、UI 成品、靜止時畫面是活的、操作有反饋。有一條不過就不交。

## 2026-11-25 方向更新（擁有者）：風格化寫實、顏色要多

擁有者的話：原作看起來寫實，而且顏色很多，所以很好塗；我們的看起來像玩具。這一節蓋過前面各節裡與它衝突的說法。

**目標**：風格化寫實（不是照片寫實，也不是塑膠玩具感）；每一個室內區域隨手都找得到可以塗進去的顏色。

**已經做的（`src/render/decor.js`、`room.js` 燈光）**
- 光：暖色太陽（0xffdfb4）＋冷色天光（半球光上 0xd6e4ff、下 0xb39a7a 的地面反彈），取代原本上下都偏暖的環境光。
- 表面細節：所有純色材質加上依世界座標算出來的斑駁、細顆粒、髒污塊、牆腳污漬、粗糙度變化與淺浮雕（一段共用的著色器）。
  吸管與所有「底色」渲染會關掉這層（吸到的是乾淨的底色）；貼平在表面上的貓會顯示跟那個表面一樣的細節，所以偽裝量測沒有變差。
- 顏色：每個區域的地上散放 15–50 公分的薄東西（墊子、布、紙、小磚，1–2 公分高，沒有碰撞），牆邊立著板子與盒子，牆上掛布與畫，
  每區一塊拼布地毯和一塊拼布掛毯（大面積多色表面）。色相每 15° 一階共 24 階，各三種深淺，飽和度壓在 0.36–0.54（染布、上漆木頭的感覺）。
  全部是純色方塊，會併進既有的靜態批次，draw call 沒有增加。
- 三塊牆面刻意留白（書房西牆、廚房北外牆、浴室隔間牆各 1.3 公尺內）：當對比，也是偽裝量測用的位置。

**還沒做到的**
- 「寫實」只做到光與表面細節；家具與小物的造型仍然是簡單幾何體，貼圖是程式畫的。沒有法線貼圖、沒有磨損邊緣、沒有接觸陰影的加強。
- 浴室和幾個小房間地上的東西偏多，看起來有點亂；沒有人看過並判斷好不好看。
- 視角較廣時 draw call 超過 300（客廳角落 354、庭院 392），這一輪沒有處理。
