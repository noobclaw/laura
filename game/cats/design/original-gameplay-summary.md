## 1. 遊戲是什麼

| 項目 | 內容 | 級 |
|---|---|---|
| 類型 | 多人捉迷藏。躲的一方（カメレオン）把自己塗成場景的顏色、擺姿勢扮成物件；找的一方（鬼／ハンター）拿漆彈霰彈槍找人 | A |

| 開發者最花力氣的功能 | 塗的東西即時同步給所有人 | A |

## 2. 回合流程

1. **大廳**：玩家在大廳裡走動。設定是走到場景裡的開關前按 E 改。鬼的人選是地上有一塊「請站在這裡」，配合「鬼抽選」倒數決定。
2. **躲藏**：躲的人自由移動、選位置、塗色、擺姿勢。這時躲的人彼此看不見，鬼待在等待區，看不到躲的人。
3. **搜索**：鬼出場用霰彈槍找人；躲的人可以挑釁、放分身、用自由鏡頭看鬼在哪。
4. **對答案**：公開所有人的位置和塗裝。生還者發紅光、被抓的發藍光，所有人用自由鏡頭飛著看，可以給別人按讚。
5. 全員投票（Y，「もうええよ」）可以提前結束躲藏或對答案階段。

## 3. 模式

| 模式 | 規則 | 級 |
|---|---|---|
| 基本 | 被打中就出局。鬼在時限內找完所有人就贏，否則躲的一方贏 | A |
| 感染（預設） | 被打中的人變成鬼，鬼越來越多，撐到最後的人最厲害。建議 6–10 人 | A |
| 雙重 | 沒有固定隊伍：全員先躲，躲藏時間結束後全員變成鬼互相找。勝負怎麼判，兩個攻略站說法不同 | A（規則）／C（勝負） |
| 逆算小雞賽跑（2.4.0 加入） | 每位躲的人的外觀和姿勢先展示給鬼看，鬼在很短的時間內反推他在哪。鬼搶先找到得分；躲的人被看到卻沒被打中累積分數；總分最高的人贏 | A |
| 隊伍戰（2026-10-28 加入） | 最多 24 人，兩隊輪流躲和找，個人分數加總成隊伍分 | A |

### 4.2 姿勢

- 第一頁 8 個（擁有者截圖）：跪坐、仰躺、彎腰、舉臂、叉腰、雙手過頭、蜷縮、趴平。
- 第二頁 10 個（6 月 23 日更新）：蜷身（背對鏡頭，把手腳藏起來）、後仰、斜身、單臂靠、深蹲、盤腿、單腳、T 字、劈腿、前彎。
- 之後的 3.x 版又加了一批表情動作。
- 影片裡看得到：擺著手勢走路，例如手扶著臉走、手往前指著走。查不到文字說明擺了姿勢移動會不會解除，至少有些手勢是可以邊走邊做的。（B，影片）
- 開發者在預告片特地放了一個蜷成一團扮成一塊肉的畫面，用意是讓人想分享。（A）

### 4.3 嵌進物體

- 身體嵌進物件太深會出現紅色警告，而且位置會暴露。（B）
- 分身可以嵌進自己的分身，不會出現警告。（C）
- 擁有者定的我們的規則：最多嵌進 1/3，超過就立刻變紅、提示不允許。

### 4.4 分身

| 項目 | 內容 | 級 |
|---|---|---|
| 數量 | 本體＋2 個 | A |
| 冷卻 | 每個 30 秒；畫面底部兩個綠色菱形 | B |
| 複製什麼 | 當下的塗裝和姿勢 | B |
| 分身被打中 | **本體也出局**，分身不是擋箭牌 | A |
| 不受重力 | 跳起來放，分身會浮在空中 | C |
| 自由鏡頭中不能按 X | 要先退出自由鏡頭 | B |
| 雙重模式 | 找到某人的任一個身體，他其餘分身立刻消失；變成鬼後不能再收回分身 | C |

### 4.5 體型與尺寸

- 開局前可選體型：標準人偶、方塊（1.9.0）、豐滿（3.x）、章魚、肌肉男、多邊形（10 月更新）。影片裡看得到方塊體型的玩家。（A）
- 房主可以改基本尺寸，也可以允許 0.5 倍的迷你尺寸（8 月加入）。（B）

## 5. 繪畫模式

| 吸管吸不到金屬度 | 玩家在開發者貼文下反映 | C |
| 面板 | 色輪、兩條直條、新舊色預覽、RGB（0–1）、HSV、8 位 Hex、歷史色、金屬感、粗糙度 | B |
| 鏡頭 | 滾輪鍵拖曳或 Alt＋左鍵轉；滾輪或 Alt＋右鍵縮放 | B |
| 陰影預覽 | V | B |
| 特殊顏料 | 夜光顏料（2.9.0） | C |
| 用姿勢或表情會退出繪畫模式 | — | C |
| 填色桶、復原、對稱 | 沒有任何來源提到 | ？ |

影片裡觀察到的手感（B，影片）：
- 塗色時鏡頭貼近身體，身體佔滿大半個畫面。
- 塗上去的顏料是亮面的，邊緣會往下流出滴痕，所以看起來像真的在刷漆。
- 玩家會在臉上畫表情（眼睛、眉毛）。
- 擁有者的評價：「真有畫畫的感覺，畫筆、畫畫的操作體驗都很棒」。

設計上的重點（A）：
- 通常只塗正面，從側面看就會穿幫。
- 身體的厚度和自己投下的影子都會暴露位置，鬼要從側面看形狀、凹凸、視差來找人，顏色是其次。

## 6. 鬼

| 項目 | 內容 | 級 |
|---|---|---|
| 外觀 | 和躲的人同一種白色人偶，手拿漆彈霰彈槍；第一人稱看到一把沾滿顏料的槍，自由鏡頭裡子彈是一道彩虹色的光，打到牆上留下彩色漆痕 | B（影片） |
| 開槍 | 左鍵，間隔 1.5 秒（1.9.0 曾加長到 2.0 秒，2.3.0 改回） | A |
| 視野角 | 105（2.6.0 從 100 調高） | C |
| 人稱 | 右鍵切換第一／第三人稱 | B |
| 移動 | 跳（空白鍵）、蹲（Ctrl）；**也能沿牆和天花板移動** | B |
| 限彈（2.3.0，房主可關） | 可設 1–99 發，建議 5。打空 −1、打中 +1、打正在逃跑的人不扣、所有鬼都打光時躲的一方立刻獲勝。沒有隨時間自動補彈 | A |
| 一槍出局 | 沒有血量 | A |
| 躲藏階段 | 在等待區，看不到躲的人 | B |
| 房主濾鏡 | 恐怖（變暗）、像素（變粗糙），用來提高鬼的難度 | B |

## 7. 遺漏排行（見落としポイント）

- 躲的人在鬼的視線內卻沒被認出來，就一直加分；距離越近、時間越長分越多（1.2.0 加入）。（A／B）
- 移動中不加分；分身也算分。（B）
- 正對時每次 45 分。（B，擁有者親見）
- 躲的人看到的是即時分數，右下角會跳數字。（B）
- 鬼看到的排行預設每 30 秒更新一次，間隔房主可調，也可以對鬼隱藏。（B）
- 公式官方沒公開（？）；沒有實質獎勵，純榮譽。（C）

## 8. 地圖

- 官方地圖 19 張。發售時的 4 張：かくれんぼの屋敷、下水道、バックルーム、屋内カントリー。之後陸續加了企鵝飯店、糖果樂園、大阪、埃及、希臘、深海、購物中心、美術館等。另有 Steam 工作坊的玩家自製圖。（B）
- 地圖有隨機要素：每局家具的擺位會變。屋敷在 2.2.0、下水道和屋内カントリー在 2.3.0 加入，預計推到全部地圖。（A）
- 地圖細節很密：裝飾、雕像、塗鴉、氣球，目的是給玩家「可以假扮的東西」。（A）
- 小圖適合人少、大圖適合人多。（B）

影片裡看到的地圖設計（B，影片，2026-11-26）：
- **全部是封閉室內**，每個畫面都有牆和天花板，看不到室外。
- **天花板低**，大約是角色身高的 1.4–1.6 倍；**房間小**，大約幾個身長寬，用門和走廊連接。
- **地上乾淨**：家具靠牆擺，房間中間只有少數幾件東西。
- **真人比例**：角色在嬰兒床、衣帽架、沙發、椅子旁邊大小正常，道具都是實物大小。
- 每張圖有清楚的主題：洞窟加小船、嬰兒房（粉紅牆、嬰兒床）、室內農場（穀倉壁畫、牛、乾草）、米色迷宮走廊、車庫（油桶）、有拱門的客廳、自助洗衣店、藍色菱格壁紙配黑白格地磚的大廳。

## 9. 畫面與角色（B，影片）

- 角色是光滑的白色人偶，像充氣玩偶：
  - 大圓頭沒有五官；
  - 脖子粗短，往下斜成溜肩；
  - 手臂粗，像從肩膀裡長出來；
  - 手是連指手套形；
  - 整個身體是一個連續的表面，看不到接縫。
- 材質很亮，像塑膠，有明顯的反光；塗上去的顏色也保持亮面。
- 介面簡潔：
  - 深色半透明底配白字；
  - 頂部一排小人圖示（白色是還活著的躲藏者，紅色是鬼）加沙漏和時間；
  - 右側是按鍵提示，左側是排行；
  - 塗色時左上角有大色輪。
- 躲法：把自己畫成燈塔、花瓶、雕像，貼在牛的人形立牌上，或彎成一團掛在門框上。

## 10. 好玩在哪（我們的判斷，非出處）

1. **對答案是最大的笑點和成就感**：「原來你躲在那裡」。所以對答案階段一定要讓所有人飛著看。
2. **遺漏排行獎勵大膽**：躲在鬼眼皮底下比躲到沒人去的角落更有分，逼大家冒險。
3. **限彈讓鬼不敢亂打**，躲的人才有機會在鬼面前活下來。
4. **塗色本身就好玩**，像在自己身上畫畫，不只是為了贏。
5. **和朋友一起玩**是核心：語音、挑釁、按讚、分享截圖都建立在多人上。
