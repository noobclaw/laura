# 塗色

## Summary

貓用 3D 筆刷直接在自己身上畫。工具完整度照原作：色輪、RGB、HSV、色碼、色票、金屬度、粗糙度、3D 取色【原作，見 reference 1.7 與擁有者提供的截圖】。

## Core Rules

1. F 開關塗色模式；左鍵塗；用姿勢輪會退出塗色模式【原作】。
2. 筆刷是一個球：滑鼠指到身體上的點為球心，球內的表面全部上色，所以轉到背面的地方不會被塗到。
3. 筆刷大小：滾輪或 `[` `]`，半徑 1–20 cm【我們定】。
4. 硬度：硬邊／軟邊兩檔【我們定】。
5. **3D 取色**：按住 Alt 點場景裡任何一點，取那一點在畫面上的顏色（含光照），同時取該材質的金屬度和粗糙度【原作有 3Dスポイト；「含光照」是我們定，因為這樣取到的顏色才真的融得進去】。
6. 一鍵填滿：把目前顏色塗滿全身【我們定】。
7. 復原：Ctrl+Z，至少 20 步【我們定】。
8. 色票：三排，第一排預設常用色，後兩排自動記最近取過的顏色【版面參考原作，內容我們定】。
9. 金屬度、粗糙度是筆刷屬性，和顏色一起畫上去。
10. 準備和搜索階段都能塗。

## 我們自己加的輔助（給新手）【我們定】

- **環境色建議**：塗色面板頂部顯示腳下、背後、左右四個取樣色，點一下就選用。
- **花紋筆**：條紋、格子、木紋、榻榻米紋四種圖樣筆刷，方向跟著筆劃走。原作沒有，如果試玩發現它讓偽裝太容易就拿掉。

## Formulas

- 筆刷權重：`w = 1 - smoothstep(r × hardness, r, d)`，`d` 是紋素的物件空間位置到球心的距離。
- 混色：`color = mix(old, brush, w × opacity)`。

## Edge Cases

- 滑鼠沒指到身體：不畫。
- 筆劃跨過身體的接縫：因為是按 3D 位置算的，接縫兩邊都會上色，不會斷。
- 換姿勢：貼圖不變，只換網格，漆留在原本的身體部位。
- 換體型：只能在開局前，進場後不能換。
- 取色點到天空或發光體：照取畫面顏色，金屬度 0、粗糙度 1。

## Tuning Knobs

貼圖解析度（預設 512，低配 256）、筆刷半徑範圍、復原步數、建議色取樣距離。

## Game Feel

- 落筆：很輕的刷毛聲，音高隨筆刷大小變。
- 取色：一聲短促的滴，色票格彈一下。
- 填滿：全身從下往上刷過一道光。

## UI Requirements

面板在右側，不擋住自己的貓。內容由上到下：環境色建議、色輪＋明度條、RGB／HSV 分頁滑桿、色碼輸入、三排色票、金屬度／粗糙度滑桿、筆刷大小與硬度、工具列（筆、取色、填滿、花紋、復原）。全部用我們自己的樣式，不照搬原作版面。

## Acceptance Criteria

- [ ] 腳本在身體上畫一筆，貼圖對應區域像素改變，背面像素不變。
- [ ] 取色：對一張紅色靠墊取色，得到的顏色與畫面上該點的顏色差 ΔE < 3。
- [ ] 8 個姿勢切換後，同一塊漆仍在同一個身體部位。
- [ ] 復原 20 步逐步還原。
- [ ] 14 隻貓同場，塗色時幀率不低於 50（中階筆電）【未驗證，需實機】。
- [ ] 連線下，別人看到我的塗裝與我自己看到的一致。
