# Game Concept：貓躲狗找（暫名）

狀態：已定稿（擁有者 2026-11-24 口頭拍板：貓躲、狗找，其餘儘量照原作玩法）。
標記：【事實】有來源；【判斷】是我們自己的設計決定；【未驗證】還沒查證或沒實測。

## Elevator Pitch

多人線上躲貓貓。貓把自己的毛塗成家裡任何東西的顏色，擺個姿勢假裝是靠墊；狗拿著網球發射器滿屋子找，球有限，打錯一發少一發。回合結束全屋揭曉，看誰就趴在狗腳邊沒被發現。

## Core Identity

| 項目 | 內容 |
|---|---|
| 類型 | 多人派對、非對稱捉迷藏 |
| 人數 | 2–14 人一房，朋友開房為主【判斷】 |
| 一局 | 5–8 分鐘【判斷】 |
| 平台 | Steam（Windows / macOS） |
| 價格帶 | 與原作同級（原作 US$5.99【事實，見 reference-original-rules.md 1.1】） |

## Core Fantasy

- 貓：我就在你眼前，你看不到我。
- 狗：這個靠墊剛剛是不是動了一下？

## Unique Hook

玩法骨架與原作相同（自己塗色融入環境＋限彈搜索＋揭曉）。我們自己的部分：

1. 主角是貓和狗，體型多樣，同一個位置胖貓和短腿貓能偽裝成的東西不一樣。
2. 家是活的：掃地機器人、風扇、門簾、魚缸都在動，會遮擋、會撞到貓、也會幫貓掩護。
3. 貓能撞倒小東西。弄出聲音是風險，也可以拿來聲東擊西。
4. 日式的家，東西多、花紋多，可塗的對象多。

## Player Experience（MDA）

- 想給的感受：緊張的憋笑、被朋友看穿的羞恥、結算時的恍然大悟。
- 會自然出現的行為：互相炫耀偽裝、狗隊語音吵架、貓故意叫一聲挑釁。
- 我們要做的機制：塗色、姿勢、限彈射擊、口哨（喵）、分身、揭曉、見落とし分數。

## Core Loop

- 30 秒：貓找位置→取色→塗→擺姿勢；狗掃視→懷疑→決定要不要花一顆球。
- 一局：躲藏準備 → 搜索 → 揭曉 → 換邊或下一張圖。
- 一晚：換模式、換地圖、換貓狗造型，比誰的見落とし分數高。
- 長期：外觀解鎖（貓狗體型、花色起手樣式、項圈）【判斷，上線後再定】。

## Game Pillars

1. **藏得住**：塗色工具夠強，環境夠豐富，認真塗的人真的看不出來。
2. **找得爽**：狗的每一槍都有重量，打中打空都有立刻的反饋。
3. **家是活的**：靜止不動時畫面也有東西在動，場景本身製造故事。
4. **一看就懂**：新玩家不看教學，兩分鐘內知道要幹嘛。

### Anti-Pillars

- 不做成長數值、不做付費變強。
- 不做快速配對大廳（原作也沒有【事實】），先做好友開房。
- 不做寫實畫風，不追照片級。
- 不抄原作的角色、地圖、介面圖樣、名稱與文案。

## Target Player Profile

一起開語音玩派對遊戲的朋友群，也適合直播。對操作要求低，對「好笑」要求高。

## Technical Considerations

- three.js / WebGL2，全程式生成美術與音效；Electron 包成客戶端（ADR-0001）。
- 房主權威連線（ADR-0002）。
- 每隻貓一張塗色貼圖，換姿勢不掉漆（ADR-0003）。

## Risks and Open Questions

| 類別 | 風險 | 對策 |
|---|---|---|
| 設計 | 貓的身體比人偶小，太好藏，狗沒體驗 | 見落とし排行、強制喵叫、限時；用試玩調 |
| 設計 | 塗色門檻高，新手塗不好 | 一鍵取色、自動填底色、教學提示 |
| 技術 | 14 人各一張可塗貼圖的同步流量 | 只同步筆劃，不同步貼圖（ADR-0003） |
| 技術 | Electron＋Steam 連線整合沒做過【未驗證】 | 垂直切片後先做一個技術原型 |
| 市場 | 被當成原作的仿冒品 | 主題、角色、地圖、UI 全部原創；商店頁不提原作名 |
| 範圍 | 一個人＋AI，內容量大 | 先一張圖一個模式做到成品，再擴 |

未決：各階段預設秒數、預設狗的數量（原作也查不到預設值【事實】），以試玩決定。

## MVP Definition

一張圖（日式的家）、基本模式、4 種貓 4 種狗、完整塗色工具、8 個姿勢、限彈、揭曉、好友開房連線。
