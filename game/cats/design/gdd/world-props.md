# 場景與物件

本檔全部是我們自己的設計【我們定】。擁有者要求：場景豐富、物體動作豐富、物品豐富。

## Summary

第一張圖是一棟日式的家。東西多、花紋多、很多東西自己會動。

## 第一張圖：日式的家

| 區域 | 內容 | 給貓的機會 |
|---|---|---|
| 玄關 | 鞋櫃、一排鞋、傘架、招財貓擺飾 | 假裝是鞋、擺飾 |
| 客廳 | 暖桌、座墊、電視櫃、書架、沙發、地毯、觀葉植物 | 靠墊、書、盆栽 |
| 廚房 | 流理台、鍋碗、電鍋、水壺、冰箱、蔬果籃 | 鍋、水果 |
| 和室 | 榻榻米、障子、壁龕（掛軸、花瓶）、棉被堆、矮桌 | 棉被、花瓶 |
| 緣側與小院 | 木地板走廊、風鈴、盆栽、石燈籠、小池塘、晾衣竿 | 石頭、衣服 |
| 二樓閣樓（之後擴充） | 紙箱堆、舊玩具 | 紙箱 |

垂直空間：書架、冰箱頂、衣櫃頂、貓爬架、樑。貓上得去，狗上不去但看得到（貴賓型看得最清楚）。

掛軸、暖簾上的日文必須是真實且正確的詞，逐條登記在 design/assets/entity-inventory.md。不出現真實品牌名與商標。

## 會動的東西

| 物件 | 動作 | 對玩法的影響 |
|---|---|---|
| 掃地機器人 | 沿路徑巡邏，碰到東西轉向 | 貓可以搭便車；會把擺好姿勢的貓推走 |
| 吊扇／電風扇 | 轉動、擺頭 | 吹動門簾和紙 |
| 暖簾、窗簾、晾的衣服 | 隨風擺 | 週期性遮擋視線 |
| 擺鐘 | 鐘擺，整點報時 | 聲音掩護 |
| 魚缸 | 魚游、氣泡 | 純氣氛，玻璃擋球 |
| 水壺 | 每隔一陣燒開、冒蒸氣、鳴笛 | 聲音掩護 |
| 風鈴 | 隨風響 | 純氣氛 |
| 電視 | 畫面閃動，光打在房間裡 | 改變附近的顏色，取色要注意 |
| 池塘 | 水波、錦鯉 | 純氣氛 |
| 光柱裡的灰塵 | 飄 | 純氣氛 |

所有會動的東西都由回合時間決定狀態（同一個時間點每個人看到的一樣），不需要逐幀同步。

## 可撞倒的小物

茶杯、橘子、毛線球、積木、空罐、紙團、小盆栽。目標每個房間 10 個以上。碰到會滾、會倒、有聲音。位置由房主同步。

## 物品數量目標

- 垂直切片（一個房間）：不重複的物件 ≥ 60 種，總數 ≥ 250 件。
- 整張圖：不重複 ≥ 150 種。
- 每個房間的主色不同，花紋至少 6 種（木紋、榻榻米、格子、條紋、花布、純色）。

## 之後的地圖（只列方向）

貓咖啡廳、夜晚的便利商店、學校教室、溫泉旅館。每張圖要有自己的「會動的東西」清單。
