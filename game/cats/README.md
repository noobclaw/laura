# 貓躲狗找 (working title)

Multiplayer hide-and-seek: cats paint themselves to blend into a lived-in Japanese house, dogs search with a limited supply of tennis balls.

Process and folder layout follow Donchitos/Claude-Code-Game-Studios (MIT). Documents are original.

- design/gdd/game-concept.md — concept and pillars
- design/gdd/systems-index.md — systems, priorities, design order
- design/gdd/*.md — one design document per system
- design/art/art-bible.md — art direction
- design/reference-original-rules.md — research notes on the reference game's rules (public sources only)
- docs/architecture/ — architecture and decision records
- production/epics/ — epics and stories
- production/gate-checks/ — stage gate records
- web/ — the game (built on branch game/cats-web)
