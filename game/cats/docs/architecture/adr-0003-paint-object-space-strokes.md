# ADR-0003：塗色用物件空間筆刷，連線只同步筆劃

## Status
Accepted（做法已在先前的 Unity 版驗證過可行；網頁版重新實作）

## Context
貓要能在自己身上任意塗色，換姿勢不能掉漆，14 人同場要能同步。

## Decision
- 每種體型有一張固定的貼圖展開。所有姿勢共用同一份展開，姿勢只改頂點位置。
- 預先烘出一張「位置圖」：每個紋素對應的靜止姿勢下的物件空間座標。
- 筆刷是靜止姿勢空間裡的一個球。落筆時把滑鼠射線打到的點換算回靜止姿勢空間，然後在貼圖空間跑一個片段著色器：每個紋素查位置圖，離球心在半徑內就上色。這一步在顯示卡上做。
- 另存一張同尺寸的材質圖放金屬度與粗糙度。
- 連線：只送筆劃（球心、半徑、顏色、金屬度、粗糙度、硬度），每筆約 20 位元組，接收端重放。新加入的玩家由房主送壓縮後的整張貼圖。
- 復原：每一筆開始前存一份髒區快照。

## Alternatives Considered
1. 螢幕空間投影貼花：會穿透到背面、換姿勢會跑掉。否決。
2. 頂點色：解析度不夠，畫不出花紋。否決。
3. 同步整張貼圖：流量太大。只用在中途加入。

## Consequences
- 展開圖的接縫不會斷筆（按 3D 位置算）。
- 展開圖要留邊距並做擴邊，否則接縫會露底色。
- 每隻貓兩張 512² 貼圖，14 隻約 30 MB 顯示記憶體，可接受。
