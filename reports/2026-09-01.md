## 附 C：工具事故与修复（采集器 UTC 日期覆盖）

**现象**：`data/2026-08-31/` 下 5 个 json 的 mtime 全部是 `2026-09-01 07:34`，昨日 09:03 采的原始快照被覆盖。

**根因**：`collectors/run_all.mjs:13` 用 `new Date().toISOString().slice(0,10)` 取目录名 = **UTC 日期**。历史上每日任务在本地 09:03 运行（= 01:03 UTC 同日），从未暴露；**今日在 07:34 运行（= 23:34 UTC 前一日）→ 落进昨日目录并覆盖。**

**已修**（本次提交含）：改为本地日期。

```js
// Local date, not UTC: a run before 08:00 CST would otherwise land in the
// previous UTC day's folder and overwrite that day's snapshot (happened 09-01).
const now = new Date();
const today = [now.getFullYear(),
  String(now.getMonth() + 1).padStart(2, '0'),
  String(now.getDate()).padStart(2, '0')].join('-');
```

修好后已重采一次 → `data/2026-09-01/`（4/4 成功），本报告全部读数取自该目录。
